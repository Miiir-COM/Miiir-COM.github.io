Omni File Browser

Load / Save / Select Folder dialogs for Unity with one API on Windows, macOS, Linux, iOS and Android. Requires Unity 2022.3 or newer. Windows, macOS, Linux, iOS, Android에서 하나의 API로 동작하는 Unity용 불러오기 / 저장 / 폴더 선택 다이얼로그. Unity 2022.3 이상이 필요합니다.

Installation설치

  1. Import the package from the Asset Store (Package Manager → My Assets).에셋스토어에서 패키지를 Import 합니다 (Package Manager → My Assets).
  2. Everything lives in Assets/OmniFileBrowser. No setup or extra packages are required.모든 파일은 Assets/OmniFileBrowser 안에 있습니다. 별도 설정이나 추가 패키지가 필요 없습니다.
  3. If your project uses only the new Input System on Unity 2022, make sure the scene has an EventSystem with InputSystemUIInputModule.Unity 2022에서 새 Input System만 사용한다면 씬에 InputSystemUIInputModule이 있는 EventSystem이 있어야 합니다.

Demo scene데모 씬

Open OmniFileBrowser/Demo/OmniFileBrowserDemo.unity (or Tools → Omni File Browser → Open Demo Scene) and press Play. To try it on a phone, add the scene to your build. The Demo folder can be deleted at any time. OmniFileBrowser/Demo/OmniFileBrowserDemo.unity를 열고(또는 Tools → Omni File Browser → Open Demo Scene) Play를 누르세요. 휴대폰에서 테스트하려면 이 씬을 빌드에 추가하세요. Demo 폴더는 언제든 삭제해도 됩니다.

Quick start빠른 시작

using Miiir.OmniFileBrowser;

// Load
FileBrowser.ShowLoadDialog(result =>
{
    string text = result.File.ReadAllText(); // paths AND Android content:// uris
    Debug.Log(result.File.Id);               // store to reopen later
});

// Save in one step (dialog + write)
var options = new FileBrowserOptions { DefaultFileName = "save.json" }.WithFilter("JSON", "json");
FileBrowser.SaveTextFile(json, result => Debug.Log("Saved to " + result.Id), null, options);

// "Save As": pick a location, write yourself
FileBrowser.ShowSaveDialog(result => result.File.WriteAllBytes(bytes), null, options);

// "Save": overwrite the file chosen earlier, no dialog
FileBrowserIO.WriteAllBytes(savedId, bytes);

// Folder
FileBrowser.ShowFolderDialog(result => Debug.Log(result.File.Id));

// async / await (null = cancelled)
var r = await FileBrowser.LoadAsync(new FileBrowserOptions { AllowMultiSelect = true });

Paths vs. ids경로와 Id

PickedFile.Id is a file path on desktop/iOS and a content:// uri on Android. Always read and write through PickedFile or FileBrowserIO so both cases work. PickedFile.Id는 데스크톱/iOS에서는 파일 경로, Android에서는 content:// uri입니다. 두 경우 모두 동작하도록 읽기·쓰기는 항상 PickedFile 또는 FileBrowserIO를 통해 하세요.

Member멤버Meaning의미
IdPath or content uri. Persist it to reopen or overwrite later.경로 또는 content uri. 저장해 두면 나중에 다시 열거나 덮어쓸 수 있습니다.
PathReal file system path, or null for Android content uris.실제 파일 경로. Android content uri인 경우 null.
GetLocalPath()Always returns a path (copies a content uri into the cache first).항상 경로를 반환합니다(content uri는 먼저 캐시에 복사).
ReadAllBytes / ReadAllText / WriteAllBytes / WriteAllTextSync IO for any id.모든 Id에 쓸 수 있는 동기 IO.
ReadAllBytesAsync / WriteAllBytesAsyncAsync IO.비동기 IO.
CopyTo(path) / CopyFrom(path)Streamed copies for large files.큰 파일용 스트림 복사.

Options옵션

new FileBrowserOptions
{
    Title = "Export level",
    Mode = BrowserMode.Custom,          // or BrowserMode.Native
    Filters = { new FileFilter("Level", "lvl"), new FileFilter("JSON", "json") },
    AddAllFilesFilter = true,
    AllowMultiSelect = false,           // Load only
    DefaultFileName = "level01",        // Save: filter extension is appended
    InitialFolder = null,               // path or content uri; null = last folder for DialogKey
    DialogKey = "levels",               // remembers the last folder per key
    ConfirmOverwrite = true,
    AllowCreateFolder = true, AllowRename = true, AllowDelete = false,
    ShowHiddenFiles = false,
    Theme = null,                       // per-dialog theme
    TouchMode = null,                   // force touch / pointer layout
    AndroidAutoRequestFolderAccess = false,
};

Global settings전역 설정

FileBrowser.SetTheme(BuiltInTheme.Dark);          // Light, Dark, Midnight, Sakura
FileBrowser.Settings.Strings = FileBrowserStrings.Korean;  // English, Korean, Japanese, or your own
FileBrowser.Settings.DefaultMode = BrowserMode.Native;
FileBrowser.Settings.Font = myFont;               // e.g. a CJK font for file names
FileBrowser.Settings.PanelSettings = myPanel;     // optional
FileBrowser.IsOpen;                               // pause game input while true
FileBrowser.Settings.MaxRecentFolders = 10;
FileBrowser.Events.Opened += () => PauseGame();   // also Closed, ErrorOccurred, BookmarksChanged

Custom themes커스텀 테마

  1. Copy Runtime/Resources/OmniFileBrowser/Themes/Light.uss and edit the --ofb-* variables.Runtime/Resources/OmniFileBrowser/Themes/Light.uss를 복사하고 --ofb-* 변수를 수정합니다.
  2. Assets → Create → Omni File Browser → Theme, then assign the USS (and optionally a font).Assets → Create → Omni File Browser → Theme으로 테마를 만들고 USS(필요하면 폰트도)를 지정합니다.
  3. FileBrowser.Settings.Theme = myTheme;

Every visual is class based (.ofb-row, .ofb-sidebar, .ofb-btn--primary, …), so extra stylesheets can restyle anything, including icons. 모든 화면 요소가 클래스 기반(.ofb-row, .ofb-sidebar, .ofb-btn--primary 등)이라 스타일시트를 추가하면 아이콘을 포함해 무엇이든 바꿀 수 있습니다.

Platform notes플랫폼별 참고

Android

  • The user grants a folder once via the system folder picker ("Add folder…" in the sidebar). The grant survives restarts.사용자가 시스템 폴더 선택기로 폴더를 한 번 허용합니다(사이드바의 "폴더 추가…"). 허용은 앱을 다시 시작해도 유지됩니다.
  • Android 11+ can't grant the root of internal storage or the Download folder itself; pick a sub-folder.Android 11 이상은 내부 저장소 최상위나 Download 폴더 자체를 허용할 수 없습니다. 하위 폴더를 선택하세요.
  • "App Storage" (Application.persistentDataPath) is always available."앱 저장소"(Application.persistentDataPath)는 항상 사용할 수 있습니다.
  • With minify (R8/ProGuard) enabled, add -keep class com.miiir.omnifilebrowser.** { *; } to proguard-user.txt.minify(R8/ProGuard)를 켰다면 proguard-user.txt에 -keep class com.miiir.omnifilebrowser.** { *; }를 추가하세요.

iOS

  • Custom mode browses the app's Documents folder, which is made visible in the Files app by a post-build step (define OFB_DISABLE_IOS_FILE_SHARING to opt out).커스텀 모드는 앱의 Documents 폴더를 탐색하며, 빌드 후처리로 파일 앱에 보이게 합니다(끄려면 OFB_DISABLE_IOS_FILE_SHARING 정의).
  • Native Load copies picked files into the sandbox. Native Save needs the data up front: use SaveFile / SaveTextFile.네이티브 불러오기는 파일을 샌드박스로 복사합니다. 네이티브 저장은 데이터가 미리 필요하므로 SaveFile / SaveTextFile을 사용하세요.

Windows / macOS / Linux

  • Custom mode: full file system, drives and volumes in the sidebar.커스텀 모드: 전체 파일 시스템, 드라이브와 볼륨이 사이드바에 표시됩니다.
  • Native mode: Win32 dialogs / macOS panels via AppleScript (not in sandboxed Mac App Store builds) / Editor panels in Play Mode. Linux falls back to the custom UI.네이티브 모드: Win32 대화상자 / AppleScript를 통한 macOS 패널(Mac App Store 샌드박스 빌드 제외) / 플레이 모드의 에디터 패널. Linux는 커스텀 UI로 대체됩니다.

Extending확장

Implement IFileSystemProvider (cloud storage, zip archives, …) and call FileSystemProviders.Register(myProvider). Its locations appear in the sidebar and favorites, recent folders, breadcrumbs and the save flow just work. IFileSystemProvider를 구현하고(클라우드 저장소, zip 등) FileSystemProviders.Register(myProvider)를 호출하세요. 위치가 사이드바에 나타나고 즐겨찾기, 최근 폴더, 경로 표시줄, 저장 흐름이 그대로 동작합니다.
