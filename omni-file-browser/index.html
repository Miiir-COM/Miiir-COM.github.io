Five lines to a save system다섯 줄로 만드는 저장 기능

"Save As" picks a location once; "Save" overwrites it later without any dialog — also on Android."다른 이름으로 저장"으로 위치를 한 번 고르면, "저장"은 다이얼로그 없이 덮어씁니다. Android에서도요.

using Miiir.OmniFileBrowser;

// Save As
FileBrowser.SaveTextFile(json, r => savedId = r.Id, null,
    new FileBrowserOptions { DefaultFileName = "save.json" }.WithFilter("JSON", "json"));

// Save (no dialog)
FileBrowserIO.WriteAllText(savedId, json);

// Load
FileBrowser.ShowLoadDialog(r => json = r.File.ReadAllText());
